# 🐍 Python Basic Commands

[](#-python-basic-commands)

> Um repositório de estudo criado para praticar os **fundamentos da linguagem Python**, reunindo exemplos práticos, comandos básicos e materiais de referência.

O conteúdo está organizado por tópicos, com arquivos **`.py`** contendo exemplos práticos e arquivos **`.md`** contendo materiais de apoio em português e inglês.

## Sobre o Projeto

[](#sobre-o-projeto)

Este repositório reúne estudos e exemplos dos principais fundamentos usados nos estágios iniciais do desenvolvimento em Python.

O projeto está organizado de forma simples e separado por tópicos, facilitando a navegação pelo código e a localização de conteúdo específico.

# Requisitos

[](#requisitos)

Para executar os exemplos Python, é necessário ter o **Python** instalado.

Verifique a instalação com:

```
python --version
```

Ou:

```
python3 --version
```

---

# Executando os Exemplos

[](#executando-os-exemplos)

Os arquivos **`.py`** podem ser executados usando uma IDE ou pelo terminal.

### Terminal

[](#terminal)

Execute o arquivo:

```
python NomeDoArquivo.py
```

Exemplo:

```
python variaveis.py
python metodos.py
python entrada_saida.py
python condicionais.py
python repeticoes.py
python operadores.py
```

### IDE

[](#ide)

Você também pode abrir o projeto em uma IDE compatível com Python e executar os arquivos diretamente.
