# 🐍 Python Basic Commands

[](#-python-basic-commands)

> A study repository created to practice the **fundamentals of the Python language**, bringing together practical examples, basic commands, and reference materials.

The content is organized by topics, with **`.py`** files containing practical examples and **`.md`** files containing support materials in Portuguese and English.

---

## About the Project

[](#about-the-project)

This repository brings together studies and examples of the main fundamentals used in the early stages of Python development.

The project is organized in a simple way and separated by topics, making it easier to navigate through the code and find specific content.

### Available Content

[](#available-content)

# Requirements

[](#requirements)

To run the Python examples, you need to have **Python** installed.

Check the installation with:

```
python --version
```

And:

```
python3 --version
```

# Running the Examples

[](#running-the-examples)

The **`.py`** files can be run using an IDE or through the terminal.

### Terminal

[](#terminal)

Run the file:

```
python FileName.py
```

Example:

```
python variaveis.py
python metodos.py
python entrada_saida.py
python condicionais.py
python repeticoes.py
python operadores.py
```

### IDE

[](#ide)

You can also open the project in a Python-compatible IDE and run the files directly.
